# Health Connect Frontend

React + Vite + Chakra UI (Horizon UI theme)

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Structure

```
src/
├── components/
│   └── Navbar.jsx
├── pages/
│   ├── Home.jsx
│   ├── Login.jsx
│   └── Register.jsx
├── theme/
│   └── theme.js
├── App.jsx
└── main.jsx
```

## Features

- ✅ React Router routing
- ✅ Chakra UI components (Horizon UI theme)
- ✅ Dark/Light theme toggle
- ✅ React Icons
- ✅ No authentication (UI only)
- ✅ Role dropdown in register (6 roles from backend)

## Roles

- PATIENT
- DIETITIAN
- DOCTOR
- SUPPORT_STAFF
- SYSTEM_ADMIN
- SUPER_ADMIN
